# Kediler Tarafından Hacklenmiş Hesap Makinesi

![Kedi](https://i.imgur.com/placeholder-kedi.jpg) *(Hayali kedi resmi, gerçekte yok)*

## Bu Nedir?

Bu, dünyanın **en ciddi** ve **en absürt** hesap makinesidir. 
Normal hesap makineleri sıkıcıdır. Bu değil. Çünkü **kediler** klavyeye basmıştır.

- Gerçekten çalışır.
- Bazen yanlış çalışır.
- Bazen "miyav" der.
- Her zaman eğlencelidir.

## Neden Bu Repo?

Çünkü GitHub'da her şey ciddi olmak zorunda değil. 
Bazen bir kedi hesap makinesini hackleyebilir ve dünya daha güzel olur.

## Nasıl Kullanılır?

```bash
python3 hesap_makinesi.py
```

Sonra sayıları gir. Kedilerin müdahalesine hazır ol.

## Özellikler

- %30 ihtimalle kedi müdahalesi
- Miyav desteği
- Sıfıra bölme koruması (kediler bile yapmaz)
- Aşırı ciddi olmayan ciddi arayüz
